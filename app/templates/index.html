How it works

  1. Designer generates a sheet (PDF to print + template), uploads a custom template, or uses the built-in BITS Hyderabad 30Q layout.
  2. Professor creates an exam on that layout and clicks in the answer key for each set, including questions with multiple correct options.
  3. Upload scans. Each sheet is read into results.csv (marked options per student).
  4. Scores are compiled into scores.csv: student ID, roster details, set, score, counts and review flags.
  5. Fix flagged sheets in the app. Scores update automatically when the key, marking or a sheet changes.
