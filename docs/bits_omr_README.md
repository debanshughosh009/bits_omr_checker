# BITS Hyderabad 30Q OMR – OMRChecker setup

The commands in this document apply to the current repository checkout.
For the end-to-end workflow, see the root [README](../README.md).

Files
- `template.json`  – sheet layout (set A–D, 13-column ID grid with per-column labels, Q1–30). Generated by `scripts/make_template.py`.
- `config.json`    – processing/threshold settings.
- `inputs/`        – put scans here (JPG/PNG/PDF). `sample_273.jpg` is the test sheet (student 273, Set D, ID 2022A7PS2018H).
- `scripts/check_template.py` – dependency-light check: overlays the template on a scan and reads every bubble.
- `scripts/validate_schema.py` – validates template/config against OMRChecker's own schemas.

Run from the repository root:
    python -m venv .venv
    # Windows PowerShell: .\.venv\Scripts\Activate.ps1
    # macOS/Linux: source .venv/bin/activate
    python -m pip install -r scans_to_csv/requirements.txt
    python -m pip install opencv-contrib-python
    python scans_to_csv/omr_to_csv.py

The reader takes scans from `input/` and writes `output/results.csv`. To use
another folder or template, pass `--scans`, `--template`, and `--config` to
`scans_to_csv/omr_to_csv.py`.

Expected for inputs/sample_273.jpg:  Set=D  ID NO=2022A7PS2018H  q1..q10 = B B C D B C C D B B, q11..q30 blank

Notes
- Template is calibrated to 1791x2576 px scans (about 215 dpi A4). Different scan size => scale or regenerate.
- Pre-printed grey bubbles (ID1='2', ID2='0', ID13='H') are read as ordinary bubbles.
- Multi-marked fields are concatenated (e.g. ID6='15'), the same way the current tool's output shows.
- ID column labels were read from the printed sheet; hidden-under-ink labels (ID6 row 6 = '7', ID7 row 1 = 'P', ID8 row 4 = 'S') were inferred from this sheet's known ID and the value sets in Options.xlsx.
